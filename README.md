## Descripcion general del sistema

Este proyecto corresponde a la Actividad Sumativa 1 de la asignatura Desarrollo Orientado a Objetos I.
Es un sistema orientado a objetos desarrollado en Java que modela las personas vinculadas a la agencia
de turismo Llanquihue Tour, ubicada en la Region de Los Lagos.

El sistema aplica encapsulamiento, composicion y herencia para representar de forma estructurada
a los distintos tipos de personas que trabajan o se relacionan con la agencia.
